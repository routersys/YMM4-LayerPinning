# レイヤー固定 for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-LayerPinning.svg)](https://github.com/routersys/YMM4-LayerPinning/releases)

---

YukkuriMovieMaker4（YMM4）上で動作する、タイムラインの一番上のレイヤーを固定するプラグインです。
固定したレイヤーは、タイムラインを縦にスクロールしても表示領域の最上部へ留まり続けます。
他のレイヤーは固定したレイヤーの下を流れていきます。
固定はレイヤーラベルの右クリックメニューから切り替え、シーンごとに保持します。

## 概要

本プラグインはYMM4の起動時に読み込まれ、タイムラインのレイヤーラベルの右クリックメニューへ「レイヤーを固定」を追加します。メニューはレイヤー1のラベルにだけ表示されます。

YMM4のタイムラインは、すべての要素をレイヤー番号とレイヤーの高さから求めた絶対座標へ配置します。固定は、この座標へスクロール量を足した位置へ固定したレイヤーだけを描き直すことで実現しています。固定していない間は描画へ一切介入しないため、YMM4の挙動も見た目も変わりません。

固定した行を最前面へ出すためにWPFのアドナー層を使用します。YMM4の視覚ツリーへは要素を追加せず、既存のスクロール領域が持つアドナー層へ描画を重ねます。二重描画を避けるための1箇所だけ、YMM4の内部処理へHarmonyによる実行時パッチで働きかけます。将来のYMM4の更新によって内部の構造が変わった場合には、パッチを適用せず固定が無効になります。その場合でもエラーにはならず、プラグインを入れていない状態と同じ表示になります。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-LayerPinning/releases/latest)ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4を起動し、タイムラインのレイヤー1のラベルを右クリックします。
4. メニュー最下部の「レイヤーを固定」を選択してください。

## 主な機能

### 1. レイヤーの固定

レイヤー1のラベルを右クリックし、「レイヤーを固定」を選ぶと固定します。もう一度選ぶと解除します。固定した状態はチェックマークで示します。

固定した状態はシーンごとに保持します。シーンを切り替えても、そのシーンの固定は維持されます。アプリケーションを終了すると固定は解除されます。

固定したレイヤーは、縦にスクロールしても表示領域の最上部へ留まり続けます。他のレイヤーは固定したレイヤーの下を流れていきます。レイヤーの高さを変更した場合には、固定した行の高さも追従します。

### 2. 固定した行の描画

固定した行は、アイテム、レイヤー線、グループ制御の背景、アイテム間の空白、レイヤーラベルのそれぞれを、元のキャンバスと同じテンプレートで描き直します。元のキャンバスからは固定したレイヤーの要素だけを取り除くため、二重には描かれません。

行の区切り線は各レイヤーの上端に描かれる作りのため、あるレイヤーの下側の線は本来ひとつ下のレイヤーが持っています。縦スクロールは任意の位置になり、固定した行の下端に行の境界が来るとは限らないため、帯の直下へ境界線を引いています。

タイムラインの長さを超えた範囲の色分けと、再生位置の縦線も固定した行へ重ねます。グリッド線はレイヤーではなく表示領域へ追従する作りのため、固定した行の中でも同じ位置へ描かれるよう扱いを分けています。

背景はレイヤーの色を不透明度0.5で塗る作りで、本来はその裏にタイムライン領域の背景があります。固定した行は他のレイヤーへ重なるため、視覚ツリーを遡って最初に見つかる不透明な背景を裏地として敷いています。

### 3. 入力座標の読み替え

固定した行の下へ他のレイヤーが潜り込むため、同じ画面の位置に2つのレイヤーが対応します。YMM4はレイヤーを座標の割り算で求めるため、そのままでは固定した行の上で右クリックしても、裏に隠れているレイヤーが対象になります。

本プラグインは、タイムラインのカーソル位置と右クリック位置を、固定した行の座標へ読み替えます。アイテムの追加、貼り付け、ファイルのドロップ、レイヤー内の空白の削除が、見た目どおりの位置へ働きます。

### 4. Harmonyの衝突回避

固定の処理にはHarmonyによる実行時パッチを使用します。YMM4はプラグインフォルダー内のすべてのDLLを同じ読み込みコンテキストへ読み込むため、複数のプラグインが異なるバージョンの`0Harmony.dll`を同梱すると衝突します。

本プラグインは、Harmonyをサブモジュールからソースビルドし、`LayerPinning.0Harmony.dll`という専用のアセンブリ名で同梱します。他のプラグインが同梱するHarmonyとは別のアセンブリとして読み込まれるため、バージョンの衝突は起こりません。

## 操作方法

| 操作 | 結果 |
|---|---|
| レイヤー1のラベルを右クリック → レイヤーを固定 | レイヤー1を固定します |
| 固定中に同じ項目を選択 | 固定を解除します |
| 縦スクロール | 固定したレイヤーは最上部へ留まり、他のレイヤーがその下を流れます |
| レイヤーの高さを変更 | 固定した行の高さが追従します |

## 制限事項

- 固定できるのはレイヤー1だけです。他のレイヤーのラベルにはメニューが表示されません。
- 固定した状態はアプリケーションの終了で解除されます。プロジェクトファイルへは保存しません。
- 範囲選択のドラッグは、開始点と移動量の両方からレイヤーを求めるため座標を読み替えていません。固定した行を始点にすると、裏に隠れているレイヤーが選択の基準になります。

---

## 注意事項

- 内部実装への依存: 固定の処理はYMM4の内部の描画の仕組みに依存しています。YMM4の更新によって内部の構造が変わった場合には、パッチを適用せず固定が無効になります。その場合でもエラーにはならず、プラグインを入れていない状態と同じ表示になります。
- 未固定時の動作: 固定していない間は描画へ介入しません。YMM4の挙動も見た目も変わりません。
- 同梱ライブラリ: Harmonyを`LayerPinning.0Harmony.dll`という専用のアセンブリ名で同梱しています。`LayerPinning.dll`と同じフォルダーへ配置してください。統合前のアセンブリを配置するとYMM4が`Mono.Cecil.dll`と`MonoMod.Utils.dll`を要求して失敗します。
- 更新通知: レイヤーを最初に固定したときに、YMM4の実行中に一度だけ新しい正式版を確認します。更新情報を取得できない場合は通知せず、そのまま動作します。プレリリースは通知の対象に含めません。
- 本プラグインを使用する前に、YMM4のプロジェクトファイルのバックアップを作成することを推奨します。
